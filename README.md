# ORBIT-X

## Autonomous Cyber Defense & Digital Twin for Space Systems

**Tagline:** A Cyber Immune System for Autonomous Spacecraft.

ORBIT-X is a controlled cybersecurity research and simulation platform. It models a spacecraft, generates telemetry, simulates authorized cyber incidents, detects and correlates anomalies, assesses mission risk, executes safe simulated defensive actions, preserves forensic evidence, and demonstrates mission continuity.

> This project is a simulation/digital-twin environment. It does not target or control real spacecraft or unauthorized systems.
